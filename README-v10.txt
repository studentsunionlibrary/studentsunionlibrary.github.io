SULARC Website v10 - Mobile Content Manager

New page:
mobile-content-manager.html

Purpose:
- Add notices from mobile
- Add events from mobile
- Add gallery albums and photo filenames
- Export a ready-made content-data.js
- No login/backend required
- No automatic upload to GitHub

Publishing steps:
1. Open mobile-content-manager.html from the live website.
2. Add/edit content.
3. Tap Download content-data.js.
4. In GitHub, replace the existing content-data.js with the downloaded file.
5. For gallery photos, upload each image file to the repository with the exact filename used in the manager.
6. GitHub Pages updates automatically.

Important:
This manager does not store private member data and should not be used for member documents.
