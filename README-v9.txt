SULARC Website v9 - Events, Notices & Gallery

New files:
- content-data.js : central editable notices/events/gallery data
- notices.html : public notice board
- events.html : public programmes page
- gallery.html : public gallery albums
- content-helper.html : local/browser helper to prepare a notice/event entry

No backend is used. Nothing entered in content-helper.html is uploaded automatically.
To publish a new notice/event, update content-data.js in GitHub and commit.

Gallery photos:
Upload approved images into the repository and add their filenames to content-data.js later.
Do not publish private member documents or unapproved child photos.
